# Code of conduct

TrackFlow contributors must help maintain a welcoming, professional, and harassment-free community.

Be respectful, assume good intent, give actionable technical feedback, and disagree with ideas rather
than people. Harassment, discrimination, threats, doxxing, sexualized conduct, and publication of
another person's private information are not acceptable.

Project maintainers may edit or remove contributions and restrict participation when behavior violates
these expectations. Report conduct concerns privately to the repository owner through the contact
options on the [maintainer's GitHub profile](https://github.com/vins13pattar). Reports will be handled
as confidentially as practical.
